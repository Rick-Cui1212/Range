# RANGE // 靶场

面向 CS 玩家的网页练枪靶场。三把枪、五种练法，不装软件，打开浏览器就能打。

---

## 怎么跑

双击 `start.bat`。

它会做两件事：在 `127.0.0.1:8765` 起一个本地静态服务，然后用默认浏览器打开靶场。

> 为什么不能直接双击 `index.html`：`file://` 下浏览器不给指针锁定（鼠标不能无限转），必须走本地 HTTP。

手动启动也行：

```bat
cd /d "D:\Users\Rick\Desktop\AI工作\range"
python -m http.server 8765 --bind 127.0.0.1
```

然后打开 <http://127.0.0.1:8765/index.html>。

**开练前建议**：按 `F11` 全屏；关掉系统鼠标加速；把设置里的 DPI 和 CS 灵敏度填成你游戏里的真实值（页面会换算成 cm/360，这个数才是能跨游戏对齐手感的量）。

## 五种练法

- **GRIDSHOT** — 七块靶交错排开，打死一块立刻在别的槽位重生。练转移、练节奏，是热身的主菜。
- **FLICK** — 场上只有一块靶，位置随机。练甩枪，练第一发。
- **SPRAY** — 一块不死的靶，只记弹着。AK 的弹道是固定的图案（前 3 发直上、中间偏右、后面左右摆），练的是"往下压多少、什么时候往哪带"。
- **LONG RANGE** — 同一间靶场往后拉到 35 米，七块靶横移、**走到一半会随机停一下**再走。给 AWM 用的，也练"等目标停稳再扣扳机"。
- **CORNER** — 20 米走廊，五个门洞（3 个固定角 + 2 个随机角）。靶子从门后探出半个身位，练的是**预瞄**：准星提前放在门框边，人一出来就打，而不是看到再拉。

## 打完了能看到什么

结算面板左半边是你的诊断：

- **弹着热区 · 墙面投影** — 每一发在靶墙上落在哪，一眼看出你是偏左、偏下还是散布大。黄点爆头、橙点命中、灰点脱靶。
- **首发偏离** — 每个目标冒头后你的**第一枪**，准星离靶身中心有多少厘米。打中就按命中的那个靶算；没打中只有擦边（1.5 米内）才计入，否则算你当时在看别处、不记。单位是厘米不是角度——角度会被距离放大，7 米和 35 米的同一次手抖读数完全不同。
- **CORNER 模式**里热区换成**相对靶心的散点图**：五个门洞在不同距离，绝对坐标没法叠在一张墙上，所以按"离靶心多少米"画，虚线环是 0.15 / 0.35 米。

## 三档难度

靶场里那块三档按钮管的是**靶子怎么动**，练习项目本身不变：

| 档 | 靶面 | 移动 | 击杀后重生 |
|---|---|---|---|
| 入门 | 放大约 22% | 死靶 | 0.95s |
| 标准 | 原大 | 慢速横移，约 3 秒变一次方向 | 0.6s |
| 硬核 | 缩小约 16% | 快速横移 + 叠一层抖动，约 1.2 秒变一次方向 | 0.4s |

难度是练"跟枪/甩枪"用的：入门先把点位定死，标准让你追一条匀速线，硬核的靶子会碎步改向，逼你边追边修正。最佳成绩按「模式 + 档位」分开存。

## 三把枪

| | 射速 | 弹匣 | 手感 |
|---|---|---|---|
| USP-S | 380 rpm | 12 | 单点，惩罚乱按 |
| AK-47 | 600 rpm | 30 | 全自动，弹道可背 |
| AWM | 45 rpm | 5 | 一枪一个，拉栓 1.15s |

爆头一枪死；身体三枪（AWM 身体也是一枪）。

## v3 换了什么（手感 + 外观）

- **后坐力带随机**：弹道图案还是固定的（AK 前 3 发直上、之后左右摆），但每发额外叠一层随机抖动——水平 ±0.10°、垂直 ±0.08°，AWM 减半。所以同一支枪、同样的压法，每局分数会有正常浮动，这是故意的。
- **开火声换真实录音**：`audio/shot-{usp,ak,awm}.wav` 来自 OpenGameArt 的 CC0 枪声包（`22 Pistol.wav` / `Unkown.wav` / `22 Magnum.wav`），用 `tools/make-samples.py` 裁成单发、降混单声道、重采样 44.1kHz，合计约 136KB。换弹/拉栓/命中/空仓仍是合成音——它们比采样更干净。播放时叠 ±4% 速率随机，所以连发不会听出"同一段循环"。
- **换弹有动作了**：枪下沉侧倾、弹匣脱出再推入（AK、USP），AWM 是拉机柄掀起复进；同时出现低模手套和一小截袖口。换弹期间开不了枪。时长 USP 2.1s / AK 2.4s / AWM 3.0s。
- **枪模没有换成外部 glTF**：查过 OpenGameArt / Quaternius / Kenney / Poly Pizza，CC0 的现代枪械 glTF 实际不存在（只有 .blend、FBX 或科幻枪）。所以保留手搓几何，改成加程序化木纹与金属磨损贴图，并把 USP 的体块整个重做了一遍。理由记在 `../docs/decisions-range-v3.md`。

## 手感是怎么对齐的

CS 的 yaw 是 `0.022 度 / count`，所以：

- 你转 360° 要推的鼠标距离 = `360 × 2.54 / (0.022 × 灵敏度 × DPI)` 厘米。
- 页面里所有转视角都按这个公式换算，填对 DPI 和灵敏度，网页里转 360° 和你游戏里转 360° 就是一样的鼠标距离。

开镜时会按 FOV 比例缩放灵敏度，和游戏里的习惯一致。

## 想调参数

都在 `js/game.js` 里，改完刷新页面：

- `GUNS` — 每把枪的射速、弹匣、伤害、后坐力、散布、拉栓时间。
- `sprayOffset()` — AK / USP 的弹道图案，按发数返回 `[横向, 纵向]` 偏移（度）。
- `GRID_SLOTS` — GRIDSHOT 的七个靶位坐标。
- `DEEP_SLOTS` — LONG RANGE 的七个靶位（更宽、更远）。
- `LONG_MOVE` — 长枪线每个档位的移动速度与漂移幅度，以及"随机停顿"的概率（`moveLong()` 里的 `dt * 0.16`）。
- `CORNERS` — 走廊五个门洞的位置、在哪一侧（`sgn`）；`cornerQueue()` 决定哪三个固定、哪两个随机。
- `TIERS` — 三档难度的靶面缩放、移动速度（`speed`）、漂移幅度（`amp`）、重生延迟（`refresh`）。
- `S.fov` / `S.csSens` / `S.dpi` — 视野与灵敏度默认值。
- `tune`（`mountViews()` 里）— 三把枪在画面里的位置、朝向、缩放。调它比改模型本身简单：`x` 往右、`y` 往上、`z` 往远，`ry` 是枪口朝左/右摆。改完刷新页面看效果。

## 记录与分享

成绩存在浏览器 `localStorage`（键 `range.best.v1`），换浏览器/清缓存就没了。

结算页可以「保存成绩卡」，导出一张 640×800 的 PNG，发群里用。

## 它不做什么

- 不联机、不排行、没有账号 —— 纯前端算分，改 JS 就能改分，所以不做可信排行榜。
- 不承诺"练了会变强"。网页靶场和真实游戏的弹道、tick、网络都不同，它保证的只是：可重复、可记录、可对比。
- 不做手机触屏评分 —— 触屏是另一套瞄准体系，硬塞进来两边都不准。
